## 주요 변경

- 저장 프로시저·함수·뷰·트리거를 탐색하고 소스와 파라미터를 확인할 수 있습니다. 실행·삭제 지원 범위는 DB와 루틴 유형에 따라 다릅니다.
- DB·SSH 비밀번호와 개인키를 SecretStorage로 이전하고 공통 실행 경계에서 읽기 전용 검사를 적용했습니다. PostgreSQL 서버의 읽기 전용 설정과 부작용 함수 검사도 보강했습니다.
- PostgreSQL에서 SSH 터널을 사용한 DB 전환과 메타데이터 조회가 같은 연결 경로를 유지하도록 수정했습니다.
- 마이그레이션 화면이 UP/DOWN SQL 내보내기와 수동 적용·롤백 상태 기록 기능임을 명확히 했습니다. SQL은 자동 실행하지 않습니다.
- 같은 VSIX를 Windows·macOS·Linux 및 VS Code 최소/stable 조합에서 검증한 뒤 OIDC로 게시합니다.

## 업데이트 안내

- 확장 ID는 `chimaek.dbunny`로 유지됩니다. 기존 연결과 저장 쿼리는 같은 확장 ID의 저장소를 사용합니다.
- 기존 인증정보는 첫 활성화 때 이전합니다. 연결 편집에서 비밀번호를 비워 두면 저장된 값을 유지합니다.
- MongoDB Shell 스타일 명령의 인자는 따옴표가 있는 JSON 문법을 사용합니다. JavaScript 표현식은 실행하지 않습니다.
- 조회 결과와 내보내기는 `dbunny.maxResults` 제한을 적용합니다. 전체 백업 기능이 아닙니다.
- 운영 DB에는 DB 자체의 읽기 전용 계정을 사용하세요. SQLite 동기 쿼리와 Redis 명령에는 서버 쿼리 timeout이 적용되지 않습니다.
- VS Code 1.85 이상이 필요합니다. 데스크톱/원격 Node.js Extension Host용이며 브라우저 전용 vscode.dev는 지원하지 않습니다.
